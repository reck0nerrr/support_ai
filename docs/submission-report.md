# Состояние сдачи Grand Mobile Support Copilot

Обновлено 31 октября 2026 под handout от 27 октября. Основной HTTP-контракт и JSONL теперь соответствуют заданию; прежние измерения движка triage-3.1 не переносятся на эту версию.

## Что реализовано

POST /triage отдаёт официальный объект: lang, category (14 кодов), priority (p0–p3), is_spam_or_duplicate, extracted, draft_reply, needs_human, confidence, reasons. make predict принимает исторический экспорт, удаляет admin-сообщения и исходы до inference, сохраняет один результат на строку. Сервис и пакетный режим используют один движок.

RAG локально ищет по 11 разделам handout: 266 пунктов и справочному разделу RP. Идентификаторы различаются по разделам, номера игрока не считаются доказательством. Восстанавливаются казахские символы cp1251, учитываются KK/UZ-запросы, для узбекского сохраняется письменность. Проверяются ссылки, маркеры и ряд опасных обещаний; смысловая релевантность требует ручной оценки.

CRM показывает официальный разбор, приоритет, источники и метрики. Вручную исправленные/отправленные ответы и эскалации сохраняются в существующем журнале. Дедупликация — одинаковые нормализованные обращения одного заявителя в пределах часа с учётом обвиняемого и вложений. Из train подготовлены 225 кандидатов шаблонов, которые не используются в ответах без проверки.

## Измеренные результаты

| Проверка | Результат | Что это означает |
| --- | --- | --- |
| Реальный valid, локальный режим | 1000/1000 строк, 0 ошибок формата | Корректность обработки экспорта и RAG, не качество LLM |
| Категории/приоритеты на valid | Нет оценки | В выдаче нет этих меток |
| Доля needs_human в offline | 100% | Резервный режим всегда требует сотрудника |
| p95 offline | 33 мс | Локальная обработка без LLM, не показатель API-задержки |
| Стоимость offline | $0 | Внешних вызовов нет |
| Синтетические сценарии | 22/22, 6 языков | Авторские проверки сценариев, не независимый benchmark |
| Accuracy offline на синтетике | 18/22 (81,8%) | Только эвристическая категория, не оценка LLM |
| Macro-F1 приоритета offline на синтетике | 1,0 | Малый авторский набор; результат не переносится на реальные данные |
| Новая LLM-версия | 1 запрос, HTTP 429 по токенам | Успешных генераций нет, стоимость без usage неизвестна |
| Ручная оценка черновиков и KK/UZ | Ожидает проверки | Оценки носителей не выдумываются |

Внешний API вернул Retry-After=25195 секунд. Полный live-прогон остановлен; сохранённая попытка не выдаётся за измерение качества/скорости LLM. Цели $0,002 за обращение и p95 ≤ 5 с для новой LLM-версии пока не подтверждены.

## Что нужно для окончательной оценки

В private/annotations.pending.jsonl подготовлены 120 обращений для независимой ручной разметки. Заполнить category, priority, language, needs_human и label_source=manual. После восстановления квоты выполнить live-прогон и make evaluate. Черновики отдельно оценить по шкале 1–5, KK/UZ — с носителями. Ошибки и отсутствующие ответы входят в отчёт, категория и приоритет считаются только на заполненных метках.

Файлы с реальными обращениями, предсказаниями, шаблонами и примерами отчётов находятся в private/, исключены из Git. Публичные synthetic contract.* не содержат записей handout. Команды запуска, контракт и методика — в [hackathon.md](hackathon.md) и [triage-contract.md](triage-contract.md).
